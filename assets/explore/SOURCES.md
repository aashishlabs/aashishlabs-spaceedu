# Solar system gallery

Five locally optimized WebP portraits from [NASA's planet gallery](https://science.nasa.gov/solar-system/planets/). Download URLs and reproducible Sharp conversion are in `../../prepare-explore-assets.cjs`.

- Mercury: MESSENGER, PIA15162 — NASA / Johns Hopkins University Applied Physics Laboratory / Carnegie Institution of Washington.
- Jupiter: Juno, PIA22946 — NASA / JPL-Caltech / SwRI / MSSS. See the linked NASA gallery for image processing credits.
- Saturn: Cassini, PIA21345 — NASA / JPL-Caltech / Space Science Institute.
- Uranus: Voyager 2, PIA18182 — NASA / JPL-Caltech.
- Neptune: Voyager 2, PIA01492 — NASA / JPL. This historic image uses enhanced color.

Earth, Venus and Mars reuse the existing `assets/ui/*-thumbnail.webp` assets; their originals and the main hero textures are unchanged. Portraits are illustrative, not to scale or consistently natural-color.

Educational facts and field notes link directly to each planet's NASA facts page in the section. NASA is a source, not an affiliate or endorser of this fictional SpaceEdu demo.
